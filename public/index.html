Exercícios da lista

Cada endpoint devolve o enunciado, o comando equivalente no mongosh e o resultado vindo do banco.

Produtos

GET/api/produtosFiltros: ?marca= ?precoMin=&precoMax= ?ordenarPor=preco&ordem=desc&limite=3 ?campos=nome,preco&semId=true
GET/api/produtos/contagemcountDocuments()
GET/api/produtos/:idBusca por ObjectId
POST/api/produtosAceita um objeto ou um array (insertOne / insertMany)
PATCH/api/produtos/:id$set nos campos enviados
PATCH/api/produtos/:id/estoque$inc — body { "quantidade": 5 }
PATCH/api/produtos/:id/preco$inc — body { "valor": 50 }
POST/api/produtos/marcar-disponiveisupdateMany com $set
DELETE/api/produtos/:iddeleteOne()

Clientes

GET/api/clientes?cidade= (aninhado) ?interesse= ?tecnologia= (arrays)
POST/api/clientesAceita endereço aninhado e arrays
PATCH/api/clientes/:id/endereco$set com notação de ponto
POST/api/clientes/:id/interesses$push, ou $addToSet com { "unico": true }
DELETE/api/clientes/:id/interesses/:valor$pull

Alunos

GET/api/alunos?curso= ?idadeMin=20 ?semestre=4 ?nota=9 ?campos=nome,curso
GET/api/alunos/media$avg sobre o array de notas
GET/api/alunos/por-curso$unwind + $group
POST/api/alunos/:id/notas$push de uma nota

Vendas

GET/api/vendas?categoria= ?quantidadeMin=3 ?ordenarPor=quantidade
GET/api/vendas/resumo$group com $sum e $avg
GET/api/vendas/faturamento$project + $multiply + $group + $sort

Pedidos

GET/api/pedidos?status= ?cliente= ?cidade= ?produto=Notebook
GET/api/pedidos/por-status$group por status
GET/api/pedidos/faturamento$unwind + $group — valor de cada pedido
GET/api/pedidos/produtos-mais-vendidosRanking a partir do array de itens
POST/api/pedidosCalcula o valorTotal a partir dos itens
PATCH/api/pedidos/:numero/status$set + $push no histórico
POST/api/pedidos/:numero/itens$push de item + $inc no total
